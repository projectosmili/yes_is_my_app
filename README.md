# Yes Is My App 💬

A Flutter chat application inspired by modern messaging apps, focused on clean architecture, state management, and dynamic message interactions.

Features

- Real-time styled chat interface
- Message bubbles for user and bot responses
- Automatic scrolling behavior
- Yes/No answer integration
- Provider state management
- Clean Flutter folder architecture
- Responsive UI

 Technologies

- Flutter
- Dart
- Provider
- Material Design

 Project Structure

```bash
lib/
│
├── config/
│   └── helpers/
│
├── models/
│
├── presentation/
│   ├── providers/
│   ├── screens/
│   └── widgets/
│
└── main.dart
```

 Getting Started

 1. Clone the repository

```bash
git clone https://github.com/projectosmili/yes_is_my_app.git
```

2. Enter the project folder

```bash
cd yes_is_my_app
```

 3. Install dependencies

```bash
flutter pub get
```

 Run the application

```bash
flutter run
```
